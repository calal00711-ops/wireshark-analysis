DNS Traffic Analysis
Objective
Capture and analyze DNS traffic using Wireshark.

Environment
Windows 11 VM
Wireshark
Tasks Performed
Captured DNS traffic
Applied DNS display filters
Generated DNS queries
Examined DNS requests and responses
Identified source and destination IP addresses
Findings
The DNS capture successfully recorded domain name resolution traffic.

DNS requests and responses were observed between the Windows 11 virtual machine and the configured DNS server.

The traffic demonstrated how DNS translates human-readable domain names into IP addresses before network communication occurs.

Skills Demonstrated
Packet Capture
DNS Analysis
Protocol Identification
Network Troubleshooting
Wireshark Filtering
